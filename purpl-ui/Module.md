# Module purpl-ui

Present Jetpack Compose paywalls that work with both local configuration and remote Purpl configuration.

`PaywallView` owns product presentation, selection, purchases, and restoration. Your app owns the surrounding navigation, tabs, toolbars, and close buttons.

# Package sh.purpl.ui

The default Compose paywall, its configuration, style, and state.

Use [PaywallView] with a local [PaywallConfiguration], a remote paywall identifier, or both. Create a [PaywallModel] to build custom product cards.
